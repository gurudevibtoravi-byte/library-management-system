# Library Management System

A comprehensive library management system with user authentication, book management, borrowing system, member management, and advanced features.

## Features

### Core Features
- User Authentication & Authorization (JWT)
- Book Catalog Management
- Member Management
- Borrowing & Returning Books
- Fine/Penalty System
- Search & Filtering
- Reservation System

### Advanced Features
- Admin Dashboard
- Member Dashboard
- Real-time Notifications
- Book Availability Status
- Borrowing History
- Fine Calculation & Payment Integration
- Book Reviews & Ratings
- Email Notifications

## Project Structure

library-management-system/

## Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- bcryptjs for password hashing

### Frontend
- React
- Redux (State Management)
- Axios (HTTP Client)
- Tailwind CSS (Styling)
- React Router (Navigation)
